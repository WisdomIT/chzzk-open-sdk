# wizbot 마이그레이션

기존 `packages/shared/src/chzzk` 함수와의 대응표입니다. 가장 큰 변화는 **토큰을 직접 전달하지 않는다**는 점입니다 — `TokenManager`가 저장·갱신·재시도를 자동 처리합니다.

| 기존 wizbot                                                                  | chzzk-open-sdk                                                             | 비고                                                                                                     |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `chzzk.authorization.accessToken({code, state})`                             | `client.auth.login({code, state})`                                         | 토큰이 tokenStore에 자동 저장                                                                            |
| `chzzk.authorization.refreshToken(...)`                                      | (자동) / `client.auth.refresh()`                                           | 만료 임박·401 시 자동. single-flight                                                                     |
| `chzzk.authorization.revokeToken(...)`                                       | `client.auth.revoke()`                                                     | ⚠️ 경로 교정: 구 `/auth/v1/revoke` → 문서 `/auth/v1/token/revoke`                                        |
| `chzzk.user.me(token)`                                                       | `client.users.me()`                                                        | 응답에 미문서 `nickname` 포함(실측)                                                                      |
| `chzzk.channel.channels({channelIds})`                                       | `client.channels.get(channelIds)`                                          | `verifiedMark` 추가                                                                                      |
| (없음)                                                                       | `client.channels.streamingRoles()` / `followers()` / `subscribers()`       | 신규. 소유자 `userRole`은 실측상 `STREAMER`                                                              |
| `chzzk.category.search({size, query})`                                       | `client.categories.search({query, size})`                                  |                                                                                                          |
| `chzzk.live.lives({size, next})`                                             | `client.lives.lives({size, next})` / `iterateLives()`                      | 자동 순회 추가                                                                                           |
| `chzzk.live.streamsKey(token)`                                               | `client.lives.streamKey()`                                                 | 문자열 반환                                                                                              |
| `chzzk.live.setting(token)` / `settingUpdate(token, d)`                      | `client.lives.getSetting()` / `updateSetting(d)`                           |                                                                                                          |
| `chzzk.chat.send(token, {message})`                                          | `client.chats.send(message)`                                               | `messageId` 문자열 반환                                                                                  |
| `chzzk.chat.notice(token, {...})`                                            | `client.chats.notice({message}｜{messageId})`                              | 둘 중 하나만 (XOR 검증)                                                                                  |
| `chzzk.chat.setting(token)` / `settingUpdate(...)`                           | `client.chats.getSettings()` / `updateSettings(...)`                       | ⚠️ 필드명 교정: `allowSubscriberInFollowerMode` (구 타입은 오타). `chatSlowModeSec`/`chatEmojiMode` 추가 |
| (없음)                                                                       | `client.chats.blindMessage({chatChannelId, messageTime, senderChannelId})` | 신규 (2026.03 API). 파라미터는 CHAT 이벤트에서                                                           |
| `chzzk.session.authClient()` / `auth(token)`                                 | `client.sessions.createClientSessionUrl()` / `createUserSessionUrl()`      |                                                                                                          |
| `chzzk.session.client(...)` / `sessions(token, ...)`                         | `client.sessions.listClientSessions()` / `listUserSessions()`              | ⚠️ `disconnectedDate` 철자 교정(구 타입 `disconnedtedDate`는 오타), 연결 중엔 필드 없음                  |
| `chzzk.session.eventsSubscribeChat/Donation(...)`                            | `client.sessions.subscribe('chat'｜'donation'｜'subscription', key)`       | **`subscription` 이벤트 추가** (구 코드에 누락)                                                          |
| `apps/chatbot/src/socket.ts` (수동 연결·`setTimeout(1000)` 구독·수동 재연결) | `client.createRealtime({auth: 'client', subscriptions: [...]})`            | connected 반응 구독, 재연결·재구독 자동, 정규화 타입 제공                                                |
| `getChatRole(badges)` (뱃지 URL 추론)                                        | `getChatRole(chat)`                                                        | 실측 `userRole` 1차 기준, 뱃지 추론은 폴백                                                               |
| (없음)                                                                       | `client.drops.*`, `client.restrictions.*`                                  | 신규                                                                                                     |

반복 메시지(repeat) 같은 앱 로직은 SDK 범위 밖이며, 기존처럼 `setInterval` + `client.chats.send()`로 구현하면 됩니다.
